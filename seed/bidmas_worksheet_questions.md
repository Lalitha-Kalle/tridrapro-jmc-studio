## Question 1
The value of 1 + 1 − 2 + 3 + 5 − 8 + 13 + 21 − 34 is

(A) −32  (B) 1  (C) 88  (D) 0  (E) −34

**Answer: (D) 0**

Group the terms with brackets: (1 + 1 − 2) + (3 + 5 − 8) + (13 + 21 − 34). Each bracket equals 0, so the total is 0.

## Question 2
Joshua is reading a 396-page book. He has read the first third of the book only. How many pages does he have left to read to finish the rest of the book?

(A) 264  (B) 124  (C) 250  (D) 199  (E) 244

**Answer: (A) 264**

Solution 1: One third of 396 is 396 ÷ 3 = 132, so he has 396 − 132 = 264 pages left.
Solution 2: He has 1 − 1/3 = 2/3 of the book left, and 396 × 2/3 = 792/3 = 264.

## Question 3
The operation Δ is defined so that aΔb = a × b + a + b. For example, 2Δ5 = 2 × 5 + 2 + 5 = 17. If pΔ3 = 39, the value of p is

(A) 13  (B) 12  (C) 9  (D) 10.5  (E) 18

**Answer: (C) 9**

pΔ3 = p × 3 + p + 3 = 4p + 3. Since 4p + 3 = 39, 4p = 36 and p = 9.

## Question 4
Operations are placed in each ◯ so that 3 ◯ 5 ◯ 7 ◯ 9 = 78. Listed from left to right, the operations are

(A) +, ×, +  (B) +, +, ×  (C) ×, ×, −  (D) ×, ×, +  (E) ×, +, ×

**Answer: (E) ×, +, ×**

Try each option:
- (A) 3 + 5 × 7 + 9 = 3 + 35 + 9 = 47
- (B) 3 + 5 + 7 × 9 = 3 + 5 + 63 = 71
- (C) 3 × 5 × 7 − 9 = 105 − 9 = 96
- (D) 3 × 5 × 7 + 9 = 105 + 9 = 114
- (E) 3 × 5 + 7 × 9 = 15 + 63 = 78 ✓

## Question 5
What is the value of the product (1 + 1/1) · (1 + 1/2) · (1 + 1/3) · (1 + 1/4) · (1 + 1/5) · (1 + 1/6)?

*(No answer options in the PDF.)*

**Answer: 7**

The product is 2/1 × 3/2 × 4/3 × 5/4 × 6/5 × 7/6. Everything cancels except 7/1, so it equals 7.

## Question 6
If a@b = (a × b) / (a + b) for positive integers a and b, then what is 5@10?

*(No answer options in the PDF, although the solution says "answer choice D is correct". The options seem to be missing from the source.)*

**Answer: 10/3**

5@10 = (5 × 10) / (5 + 10) = 50/15 = 10/3.

## Question 7
Suppose that a ∗ b means 3a − b. What is the value of x if 2 ∗ (5 ∗ x) = 1?

*(No answer options in the PDF.)*

**Answer: x = 10**

Let 5 ∗ x = y. Then 2 ∗ y = 3 × 2 − y = 1, so y = 5. Then 5 ∗ x = 5 × 3 − x = 5, so x = 10.

## Question 8
Suppose that a ⊗ b = ab − a − b. If (3 ⊗ x) ⊗ 3 = 11, then x = ____.

*(Fill in the blank; no options.)*

**Answer: x = 5**

Let 3 ⊗ x = y. Then y ⊗ 3 = 3y − y − 3 = 11, so y = 7. Then 3 ⊗ x = 3x − 3 − x = 7, so x = 5.

## Question 9
Suppose that A☆B means 3A − 2B. What is the value of x if x☆(4☆1) = 7?

A. 7  B. 8  C. 9  D. 10

**Answer: C. 9**

4☆1 = 3 × 4 − 2 × 1 = 10. Then x☆10 = 3x − 20 = 7, so x = 9.

## Question 10
Harry and Terry are each told to calculate 8 − (2 + 5). Harry gets the correct answer. Terry ignores the parentheses and calculates 8 − 2 + 5. If Harry's answer is H and Terry's answer is T, what is H − T?

A. −10  B. −6  C. 0  D. 6  E. 10

**Answer: A. −10**

H = 8 − 7 = 1 and T = 8 − 2 + 5 = 11, so H − T = 1 − 11 = −10.
